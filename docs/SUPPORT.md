# Support Channels (Private Preview)

Get help with the Reveal AI Add-On through dedicated support channels for private preview customers. This guide explains where to go for different types of questions and what response times to expect.

> **Note**: As a private preview customer, you have direct access to the Reveal AI engineering team.

## Quick Reference

| Issue Type | Best Channel |
|------------|--------------|
| Quick questions, configuration help | Discord |
| Bug reports, detailed issues | GitHub |
| Feature requests, feedback | GitHub or Discord |
| Complex implementations, architecture | Weekly Check-ins |

---

## Discord (Private Channel - Fastest for Quick Questions)

**Channel**: Private `#reveal-sdk-ai-preview` channel

**Access**: Your Reveal sales representative will provide you with a private Discord invite link. If you're already a member, they'll add you to the channel. This is a **private channel** exclusively for preview customers.

**Best For**:
- Quick configuration questions
- "How do I...?" questions
- Sharing tips and tricks with other preview customers
- Troubleshooting with Reveal team and peer support
- Real-time discussions during testing

**Response Time**:
- Usually within 4 hours during business hours (9 AM - 5 PM EST, Mon-Fri)
- Reveal AI engineering team monitors actively
- Other preview customers may respond faster

**How to Get Help**:

1. Search existing messages first (Ctrl+F / Cmd+F) to see if your question is already answered
2. Post your question with:
   - Error messages and logs
   - Relevant configuration (redact API keys)
   - What you've already tried
   - Code blocks for readability

---

## GitHub Issues (For Bugs and Feature Requests)

**Repository**: https://github.com/RevealBi/sdk-samples-ai/issues

**Best For**:
- Bug reports that can be reproduced
- Feature requests with detailed specifications
- Documentation improvements
- Sample code issues
- Public discussion of enhancements

## Community Guidelines

When asking for help:

✅ **Do**:
- Search existing Discord/GitHub threads first
- Provide context and details
- Redact API keys and sensitive information
- Share relevant code snippets
- Be patient and respectful
- Follow up when issue is resolved

❌ **Don't**:
- Post full API keys or credentials
- Submit duplicate questions across multiple channels
- Expect instant responses
- Post personal/company sensitive data publicly
- Demand specific features without justification
